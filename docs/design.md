# 练呗：日常记录与反馈

目标：用低成本输入持续积累个人日常数据，再逐步改善回看与反馈。用户已授权制作 Android App。

## 首版范围
- 饮食：餐次、食物文字、可选备注。
- 睡眠：入睡与起床时间，支持跨午夜，默认归属起床日期。
- 训练：项目、时长，可选动作、组数、次数、重量。
- 消费：金额、分类、备注；保留月度合计。
- 今天状态：心情、精力快捷选择，可选文字。
- 随手记与自定义：自由文字；创建自定义记录类别，可反复使用。
- 统一按日期浏览，可补记、编辑、删除；关闭应用后数据保留。
- 默认离线、本机保存，无登录；提供用户主动导出备份。

## 产品原则
不强迫填写全部字段。记录时间默认现在，允许修改。空白不等于零。所有首页统计来自真实记录，不放示例数据。删除需确认，金额按分保存。

## 界面
暖白背景、深绿色主色。首页展示日期导航、六类快捷卡片、当日时间线。录入使用简洁表单与快捷选择。自定义类别在随手记入口管理。支持大字体及滚动。

## 技术与验证
Kotlin、Jetpack Compose、Material 3、Room。构建 debug APK；校验输入规则、跨午夜睡眠、金额转换、数据持久化，以及六类录入回看路径。模拟器与真机验证分别记录证据。

## 后续能力
已讨论的支付通知识别与小米超级岛需要独立适配和真机验证，不能把展示接口当成支付数据来源。主线先完成记录，再接入这些低成本输入增强。年费摊算已移除。
