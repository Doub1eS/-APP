# 0.4.0 订阅记录交付

## 使用
底部「订阅」→「添加订阅」→填写名称、金额、周期、首次扣费日，可粘贴缴费链接→保存。
卡片或日历中点击「去缴费」打开网址；完成付款后返回「确认付款」，也可关联已经记好的消费。
链接由用户填写，支持HTTP/HTTPS网页；能否直接打开服务商App取决于系统对该网址的处理。
本阶段到期信息在应用内查看，不提供后台自动催缴通知；不执行自动扣款。JSON导出包含订阅和付款关联。
