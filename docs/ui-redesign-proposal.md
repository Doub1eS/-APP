# 练呗 UI 与可视化改版提案

日期：2026-10-15。状态：用户已确认推荐方案，已实施；验证证据见 ui-v3-verification.md。

## 目标

覆盖现有六类日常记录、自定义类别、历史回看、编辑删除、导出、支付待确认。让快速记录更轻松，让数据能够按日、周、月回看。保留本机离线数据及已有支付确认流程。

## 调研证据

- Cashew：https://github.com/jameskokoska/Cashew 及 https://cashewapp.web.app/ 。实际查看官网第一张宣传截图：圆角账户卡片、绿色主色、大数字、预算进度和趋势线。借鉴层次、间距和卡片语言；不使用其代码或品牌素材。截图参考位于 ui-references/cashew-1.jpg。
- Wallet：https://budgetbakers.com/en/products/wallet/features/ 。官方功能页展示分类消费金额、占比和预算总览；借鉴“总额—分类—明细”的信息顺序。
- Actual Budget：https://actualbudget.org/docs/reports/ 。实际查看官方报表截图：顶部摘要卡、下方趋势图、模块化报表。官方说明支持日期过滤及日历报告。借鉴摘要与图表结合；手机采用单列，避免照搬桌面密集布局。截图参考位于 ui-references/actual-reports.webp。

## 方案比较

1. 推荐：生活手账风格。暖白、森林绿、低饱和分类色；适合消费与健康记录并重。
2. 财务仪表盘风格：强调金额和密集图表，消费很突出，但其他生活记录容易成为附属。
3. 高饱和彩色打卡风格：入口醒目，但图表颜色和长期阅读容易疲劳。

## 推荐设计

### 视觉体系

暖白背景 #F7F8F2，白色卡片，主色 #24634C，深色文字 #202B25。饮食橙、睡眠靛蓝、训练绿、消费蓝、状态玫瑰、随手记棕，颜色搭配文字与统一线性图标。浅色底不能充当正文文字色。圆角 20–24dp，页面边距 20dp，卡片间距 12–16dp，触控区域至少 48dp。采用系统中文字体，摘要数字放大，正文不低于 14sp；支持系统字体缩放。

### 页面结构

- 今天：日期切换与日历选择、当天记录摘要、六类快捷记录入口、按时间排序的记录卡片。没有数据时显示引导，不生成示例数据。
- 回看：周/月切换、上一期/下一期、六类筛选、对应摘要和图表、该范围记录明细。点击日期或图表条目能定位明细。
- 我的：导出记录、自定义类别说明与入口、支付识别设置和数据保存说明。导出仍使用系统文件选择器并明确成功或失败。
- 支付待确认：从今天的数量入口和我的页进入。先展示待确认卡片，设置放在可展开区域；突出金额、商户、时间、分类、确认入账、忽略。演示功能放在设置区。

### 各功能可视化

| 功能 | 摘要 | 图形及交互 |
| --- | --- | --- |
| 消费 | 期间总额、笔数 | 分类环形图配金额及占比列表；每日金额柱状图；分类可筛选明细 |
| 睡眠 | 有记录日均睡眠、记录天数 | 每日睡眠时长柱状图；点击日期显示入睡至起床；缺失日期显示未记录 |
| 训练 | 次数、已填写的总时长 | 每日分钟数柱状图、项目次数横条；未填时长的训练仍计次数并单独提示 |
| 饮食 | 记录次数、记录天数 | 记录日期分布、餐次卡片与食物文字；历史自由标题归入其他，不推断营养或热量 |
| 今天状态 | 各心情出现次数 | 日历色点与心情分布横条；当天多条可以查看全部；能识别的精力选项另列分布 |
| 随手记与自定义 | 记录篇数、活跃天数 | 记录日历、类别次数横条、按标签筛选的文字卡片 |

### 录入

统一顶部标题和返回按钮；类别图标与浅色提示区；快捷选项显示选中态并自动换行；金额和时长使用数字键盘。日期与时间提供系统选择控件。底部保存操作在键盘弹出时仍可达，错误紧贴字段。睡眠实时预览时长；训练继续允许备注填写动作、组数和重量。所有编辑、补记、删除和自定义类别能力保留。

## 数据规则

- 图表只使用 records 中的实际记录；pending payments 不进入消费合计。
- 金额仍按分计算，显示两位小数；图形比例使用转换后的数值，避免整数除法。
- 周为周一至周日，月为自然月；当前周期未来日期不计入已过天数。
- 睡眠按起床日期聚合，同日多条累计后计算有记录日平均；清晰标注口径。
- 空白不解释为零睡眠、零运动或未进食；展示“未记录”。消费显示的是“已记录消费”。
- 心情按现有文字类别统计，不将开心、平静、低落等强行转换成健康评分；无法识别的自由文字归其他。
- 精力目前与备注共用字段，仅对明确匹配的选项统计，不猜测自由文字。
- 图表都提供数值标签或列表替代，零数据和单条数据都有明确状态。
