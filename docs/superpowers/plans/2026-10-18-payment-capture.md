# 支付自动识别强化 Implementation Plan
Goal: 完善小米15 HyperOS 3 / Android16的微信、支付宝通知自动采集，保持确认入账。
Architecture: PaymentParser纯规则识别；PaymentCapture统一提取通知/持久化；PaymentDiagnostics仅存状态和固定原因。NotificationListener负责连接、恢复与转交。现有Room payments唯一键保持。
Tech Stack: Kotlin / Compose / Room / NotificationListenerService。
用户已要求优先实现自动识别。沿用现有工作目录，保留未提交功能，不建立空白分支。

- [x] Parser：付款成功出现在标题、明确实付金额与优惠、多种商户字段；拒绝普通聊天/退款/收款/不确定金额。先写失败测试。
- [x] Capture：读取bigText/text/textLines，去重字段；交易号与key+事件时间+金额身份映射去重；无稳定时间/交易号时保留待确认并明确限制。恢复连接只检查当前通知，不宣称补回完整历史。数据库确认记录不可重复创建。
- [x] Diagnostics/UI：开启状态、授权、真实连接、提醒权限、最近来源通知/识别结果、固定跳过原因；手动重连、系统设置跳转失败可恢复。保留演示并说明不验证微信支付宝链路。
- [x] 验证：单元测试、模拟器设备测试、实际界面；打包0.6.0。真机未连接时明确未完成微信/支付宝真实通知验收。

约束：不保存通知原文，不上传数据；不绕过Android16敏感内容遮盖；不使用无障碍或银行短信新权限；不自动推定实际付款成功以外的交易。
真机验证需要用户支付通知样本（已询问，可在现有规则完成后继续校准）。
