# 支付宝交易提醒识别修复

日期：2026-10-21。基于 0.8.0 的修复构建，保留原版本号。

## 现场证据与修复

- 用户提供支付宝通知截图：标题“交易提醒”，正文以“你有一笔89.00元的支出”开头，随后为“领2元小…”。
- 采集诊断的接收时间随后更新，来源为支付宝，拒绝原因为“不支持的支付服务标题”。说明该通知已经投递到采集进程，旧解析规则缺少这个模板。
- 仅对支付宝包及“交易提醒”标题增加该模板。支出金额必须位于正文开头，格式明确。
- 优惠金额不会替代已标明的支出金额；仅明确“领／领取…元（小）红包”的优惠邀请不触发红包交易排除，其余退款、转账、红包交易仍排除。
- 多笔支出、冲突的实付标签、负数、零元及格式错误继续拒绝。
- 微信既有识别规则保持不变。

## 当前边界与后续验证

- 当前流程是自动采集到“支付待确认”，用户确认后计入消费。
- 用户已划掉本次通知，未补造或模拟这笔真实消费；新版本对这条完整通知的端到端验证尚未完成。
- 截图的优惠尾文被截断；测试中的完整优惠邀请为合成边界样例，不能视为已获取实际完整正文。
