# 工资单、累计个税与月度预算

## 使用口径

入口：今天、回看或我的 → 工资与预算。按发薪月份填写实际到账金额，一月一张工资单；同月再次保存更新原记录。工资归属月份不同可写在备注中。

用户工资模板固定深圳，默认税前17,000元，四项基数13,300元：养老8%（1,064元）、医疗0.5%（66.50元）、失业0.2%（26.60元）、公积金5%（665元）。个人社保合计1,157.10元，含公积金合计1,822.10元。以上是用户提供的个人参数，不代表深圳全部参保人适用比例；不推算单位缴费。

工资记录保存当时的基数和比例。修改默认模板只影响新建工资单；历史月份可单独编辑。实际到账与估算应到账分别显示，差额不自动视为个税或额外消费。

## 累计个税

按居民个人普通工资薪金累计预扣法计算：累计收入减去个人社保、公积金、每个已记录受雇月5,000元基本减除费用及专项附加扣除，得到累计应纳税所得额；套用七档税率和速算扣除数，扣除此前已预扣税额，得到本月估算个税。本月计算小于0时按0显示，不自动生成退税。

年中开始记录时，可填写起算月份、此前累计应纳税所得额及已预扣税额；已有期初覆盖的旧月份不再重复累计。不同年度分别起算。缺少历史月份、期初未确认或专项附加扣除未确认时明确标为估算。实际工资单提供的已扣个税可用于后续月份校准。

不包含年终奖单独计税、多雇主汇算、劳务报酬等税务情形。公式来源：[国家税务总局《个人所得税扣缴申报管理办法（试行）》](https://fgk.chinatax.gov.cn/zcfgk/c100012/c5194838/content.html)。

## 月度收支与预算

- 收入取当月工资实际到账；支出取现有已入账消费。社保、公积金、个税只在工资条展示，不再从实际到账收入重复扣除。
- 饮食和订阅通过其关联消费计支出，待确认付款不计入。工资收入尚不包含其他收入来源。
- 总预算和九大分类预算按月份保存；分类预算与总预算分别比较，不将两者相加。
- 未设置预算与0元预算不同；0元可表示该类当月不计划支出。超支显示超出金额，不隐藏负余额。
