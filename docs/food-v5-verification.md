# 0.5.0 饮食与消费关联

## 使用
「今天 → 饮食」：选餐次，可填写吃了什么、拍照/选图、价格。填价格自动生成餐饮消费；也可关联既有消费，避免再记一笔。

「我的 → 添加示例数据」：加入7天日常、相关餐费和3条示例订阅，重复添加不重复生成。示例计入统计并标记，可通过「清除示例数据」移除，个人记录保留。

## 数据规则
- 饮食显示关联消费的金额，不重复计算支出；金额留空是未知，不是0元。
- 改价更新自动生成的消费；改成关联已有消费会移除旧自动消费，避免重复。
- 删除饮食、清空价格保留实际消费；删除消费会解除饮食关联。
- 照片草稿在缓存中，保存记录后转存私有照片目录；引用移除后回收永久照片。图库原图不改动。
- Room 3→4增加food_entries，旧日常、支付和订阅保留。JSON版本3包含饮食关联及照片Base64，目前仍不支持导入。
