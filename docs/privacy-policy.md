# 练呗隐私政策

更新日期：2026年10月24日  
适用应用：练呗（Android，包名 `com.lianbei.daily`）  
项目维护账号：[Doub1eS](https://github.com/Doub1eS)  
联系与反馈：[练呗项目反馈页面](https://github.com/Doub1eS/-APP/issues)

练呗是一款个人日常记录应用。本政策说明当前版本如何处理数据，以及拟接入华为运动健康时应遵循的数据处理范围。**华为睡眠自动同步目前处于申请准备阶段，尚未完成接入；本政策不表示该能力已获得华为审批或已经可用。** 实际启用前会通过应用说明具体数据范围，并单独取得健康数据处理及平台授权。不同意可选功能不影响使用现有手工记录。

## 一、当前处理的数据与用途

| 功能 | 数据 | 用途与处理方式 |
|---|---|---|
| 日常记录与回看 | 你主动填写的饮食、睡眠、训练、状态、随手记、类别和日期时间 | 在本机保存、编辑、统计与按日期回看 |
| 消费与订阅 | 你填写或确认的消费金额、商户、分类、订阅、付款关联和缴费链接 | 本地记账、预算和可选到期提醒；不会代你付款 |
| 工资与预算 | 你填写的工资、扣缴参数、年度期初及预算 | 在本机生成收支和估算结果；不向开发者上传 |
| 饮食照片 | 你通过系统选择器选择或通过系统相机拍摄的照片 | 导入、压缩并保存到应用本机目录，用于对应记录 |
| 可选支付通知识别 | 微信、支付宝支持的支付通知内容，以及识别后的金额、商户、来源、日期、时间和去重身份 | 在本机过滤、识别并生成待确认记录；通知原文不写入诊断日志，开发者不会因此接收聊天或通知内容。去重身份可以包含通知/交易信息的哈希值 |
| 本机运行诊断 | 应用进程的内存、CPU、线程、文件读写、连接状态、电量、充电、温度、系统提供的本应用退出原因，以及固定采集处理结果 | 排查应用中断、漏采和资源异常；数据只留在本机，用户手动导出后自行决定是否提供给他人 |
| 备份与恢复 | 用户选择导出的记录、照片、消费关联、订阅、支付去重信息及财务数据 | 通过系统文件选择器导出JSON或导入所选文件；备份可能含敏感信息，由用户选择保存位置和保管 |

当前版本的日常记录无需注册练呗账号；没有练呗云端账本或面向开发者的自动健康数据上传功能。应用不集成广告或统计上报服务。操作系统、系统文件选择器、用户选择的云盘、浏览器或其他应用可能按各自规则处理数据，不应将其处理误认为练呗的本地处理。

## 二、权限与可选能力

- **通知使用权**：只有主动授权后，系统才会向监听服务提供通知。练呗在本机按来源过滤，识别支持的付款通知；其他来源不用于记账。不读取支付应用的历史账单，不控制支付页面。你可在系统「通知使用权」中撤销。
- **发送通知**：用于待确认付款、用户开启的订阅提醒、监听检查及用户开启的后台常驻状态。拒绝后仍可在应用内查看已经保存的记录，但外部提醒可能不可见。
- **前台服务与开机广播**：用于恢复用户已开启的支付通知采集。常驻服务有状态通知，可在应用中关闭；系统清理或强停仍可能中断。
- **文件和照片**：通过系统选择器取得你选择的单个文件；拍照调用系统相机。不申请遍历通讯录、通话记录或所有相册文件来完成日常记录。
- **运行诊断**：沿用现有应用进程低频记录，不另起诊断常驻服务、不使用唤醒锁、不录音或采集屏幕。

你可以在系统应用权限和应用内相应设置中关闭可选能力。撤销权限不会自动删除你此前已确认保存或自行导出的记录。

## 三、拟接入华为运动健康的睡眠数据

本节是拟上线功能的数据范围说明，只有华为授予练呗相应接口权限、功能完成联调且用户单独授权后才适用。

1. **数据来源和范围**：华为穿戴设备先同步到华为运动健康，练呗再通过获批的官方能力读取用户授权的睡眠记录、入睡/起床时间、实际睡眠时长，以及平台实际开放的睡眠分期。拟申请最近1个月睡眠历史，用于首次补齐和补充延迟修订；不申请一年历史。
2. **使用目的**：将用户自己的睡眠按日期、周、月展示，减少手工输入，按来源身份去重并修正延迟同步。不得将时间跨度冒充实际睡眠时长，不猜造缺失分期或评分。
3. **只读和最少范围**：本次方案不向华为写入数据，不申请心率、血氧、实时心跳或其他无关健康信息。平台授权范围与功能实际使用范围以最终说明和单独授权为准。
4. **授权与第三方处理**：拟通过华为帐号及Health Service Kit完成授权。华为SDK的实际版本、必要数据处理及隐私链接将在集成前补充告知；当前未集成这些SDK。练呗不要求你向开发者提供华为账号密码、验证码或App Secret。华为运动健康是否上传云端由其设置和政策决定，不能因此承诺整条同步链路完全离线。
5. **存储与分享**：拟读取的数据保存到本机，不向练呗开发者的服务器上传，不出售、不用于广告画像，不向其他用户公开。你主动导出的备份和报告由你控制保存及分享。
6. **撤回授权**：可通过华为运动健康「我的 → 隐私管理 → 数据分享与授权」或该版本相应入口撤销对练呗的授权。撤销后停止新的读取；已导入本机的数据可按应用内删除功能处理，彻底清除可使用系统清除应用数据。正式上线时应提供与这些说明一致的操作入口。

睡眠等健康数据具有较高敏感性。处理的必要性在于实现你选择的自动记录和回看；泄露可能影响隐私。你可拒绝自动同步，继续使用手工记录。平台或开发者权限未开通、设备未同步、网络或系统限制时，自动同步可能延迟或不可用。

## 四、保存期限和删除

- 日常、支付、财务和拟导入的健康记录保存在本机，直到你删除、清除应用数据或卸载。删除单条记录不一定同时清除全部去重标识或关联信息；要清除全部本机数据，可使用系统「清除应用数据」。
- 运行资源样本在应用运行时按最近7天、每进程最多336条保留；固定通知处理诊断最多100条，连续相同忽略结果会合并。应用停止时无法准时执行淘汰，恢复后按规则处理。系统本身保存的进程退出记录由系统管理。
- 导出的JSON、照片副本、云盘文件和已分享给第三方的副本不受应用内删除或7天保留规则控制，请到相应保存位置自行删除。
- 当前练呗不提供云端账户，因此没有练呗云端账号注销流程。可通过删除记录和清除应用数据终止本地保存；第三方账号与授权由第三方平台管理。

## 五、保护、共享与访问

记录默认位于Android应用私有存储中，不代表其在所有设备环境下绝对安全。请设置设备锁屏，保护备份和导出文件，避免向不信任的人公开健康、财务信息。练呗不将记录出售或用于自动化商业画像，也不主动向境外服务器上传应用记录；你主动打开外部页面、选择第三方存储或分享文件时，相应服务的处理以其政策为准。

你可以在应用中查阅、更正、删除已有记录，并通过备份导出复制本机数据。平台范围与功能尚未开放的，不应将「无数据」当作权限已开通或同步成功。

## 六、反馈、未成年人及政策更新

如对数据处理、授权或本政策有疑问，请通过[项目反馈页面](https://github.com/Doub1eS/-APP/issues)联系维护者。该页面公开可读，提交反馈可能需要GitHub账号；**不要在公开议题中上传健康报告、完整备份、电话号码、证件、密码或授权凭据**。涉及私密信息时先仅说明请求类型，再与维护者约定非公开沟通方式。当前测试方案面向开发者本人及获准测试者，不针对未成年人提供健康数据服务。

本政策会随功能和实际数据范围更新。涉及新增敏感数据处理、共享或权限变化时，应在应用内明确告知并重新取得必要同意。公开发布政策文本本身不等于华为审批通过，也不替代应用中的单独授权步骤。
