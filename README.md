# 练呗

原生 Android 日常记录应用。饮食、睡眠、训练、消费、今天状态、随手记与自定义类别统一按日期回看。

数据保存在本机 Room 数据库，不需要登录。「我的」页面提供 JSON 导出，卸载前请保存需要保留的记录。当前导出文件供备份与查看，尚无导入入口。

## 当前版本 0.6.0

- 四个主入口：今天、订阅、回看、我的。饮食照片/餐费关联消费，附可添加和清除的示例数据。
- 消费支持九大类及小类，手动记录与支付确认共用分类；金额优先录入、分类网格展示。
- 微信/支付宝通知保守识别，先生成待确认再由用户确认入账。新增监听连接状态、授权提示、自检、重连和诊断。
- 小米15真机已验证一次微信付款通知到待确认账目的链路；**从最近任务划走后监听会停止，持续后台运行尚未解决**。
- 退款、转账、红包暂不记账。尚未实现无障碍服务或独立轻量采集进程。

详见[当前验证记录](docs/payment-v6-verification.md)与[后续改进计划](docs/next-steps.md)。APK、真机截图和原始诊断仅保存在本机，不提交到仓库。

## 0.3.0 界面与可视化

暖白与森林绿主题，底部「今天 / 回看 / 我的」导航。六类记录提供独立配色、统一图标和卡片。

- 回看支持自然周、自然月、历史周期及明细筛选。
- 消费提供分类环形图、金额占比、每日金额柱状图。
- 睡眠提供每日时长与有记录日平均值；训练提供时长与项目次数，未填时长明确标注。
- 饮食、心情、随手记提供记录日历与分类分布，自定义类别可筛选。
- 录入增加选中态快捷选项、系统日期时间选择、数字键盘、睡眠时长预览及固定保存按钮。
- 支付待确认突出金额和操作，识别设置折叠展示。导出入口移动到「我的」。

研究来源和设计见 [改版提案](docs/ui-redesign-proposal.md)。安装包、实际截图和验证记录见 [新版交付说明](docs/ui-v3-verification.md)。

## 0.4.0 订阅记录

- 底部「订阅」入口：概览、彩色卡片、扣费日历、月度预计扣费及分类占比。
- 支持周/月/季度/年付，月末和闰年保持原始周期锚点；支持编辑、停用、恢复、删除。
- 每条订阅可填写完整的 HTTP/HTTPS 缴费网址，点击「去缴费」交给浏览器或对应应用打开。打开链接不会自动记录付款。
- 付款完成后选择「确认付款」，核对计划日期、实际付款日期及金额；可关联已有消费，避免重复记账。
- 预计费用按扣费日期统计，不做年费摊算；已有实际消费不受改价、停用或删除订阅影响。
- 数据库从旧版自动迁移；JSON导出版本2包含订阅与付款关联。到期提示目前在应用内查看。

## 本机开发

### 0.5.0 饮食与消费

饮食一次记录餐次、可选文字、单张照片与可选金额。填写金额自动生成餐饮消费；支持关联已有消费，金额从关联消费读取，统计不重复计算。照片支持相机和图片选择器，并复制压缩到应用本地目录；JSON版本3包含照片Base64和饮食关联信息。

改价同步更新饮食自动生成的消费；关联既有消费时保留其金额和日期。清空价格只解除关联，删除饮食也保留消费；界面操作前均有说明。

「我的 → 添加示例数据」可添加最近7天的日常和3条订阅；重复点击不重复添加。示例计入统计，记录上有“示例数据”标记。「清除示例数据」仅移除示例及其自动生成的消费，保留个人记录。

若本机模拟器默认渲染启动失败，可使用已验证的软件渲染命令：

```powershell
& "F:\lianbei-build\.tools\android-sdk\emulator\emulator.exe" -avd LianBei_Test -gpu software
```

Kotlin 2.1.20、Compose、Material 3、Room 2.7.1；最低 Android 8.0，编译 SDK 35，Gradle 8.11.1。JDK 17 或兼容的 JDK 21。

用 Android Studio 打开项目并设置 SDK，或者运行：

```powershell
./build-local.ps1 -Test
# 使用本机已有代理时按实际端口传入
./build-local.ps1 -Test -ProxyPort 7897
# 模拟器或测试手机连接后
./build-local.ps1 -DeviceTest -ProxyPort 7897
```

安装包构建目标：`app/build/outputs/apk/debug/app-debug.apk`。
