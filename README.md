# 练呗

原生 Android 日常记录应用。饮食、睡眠、训练、消费、今天状态、随手记与自定义类别统一按日期回看。

数据保存在本机 Room 数据库，不需要登录。「我的 → 数据与备份」支持 JSON 导出与恢复，卸载前请保存需要保留的记录。

## 当前版本 0.9.0

- 四个主入口：今天、订阅、回看、我的。饮食照片/餐费关联消费，附可添加和清除的示例数据。
- 消费支持九大类及小类，手动记录与支付确认共用分类；金额优先录入、分类网格展示。
- 今天、回看和我的新增「工资与预算」：按到账月记录实际工资，显示个人社保、公积金与累计预扣个税估算。工资保存当时参数，支持年度期初和实际扣税校准；资料不全时提示估算。
- 月度收入按工资实际到账、支出按已入账消费计算，缴费和个税不重复扣账；总预算及九大分类预算按月独立保存，支持0元预算与超支提示。详见[工资与预算口径](docs/payroll-budget.md)。
- 微信/支付宝通知保守识别，先生成待确认再由用户确认入账。新增监听连接状态、授权提示、自检、重连和诊断。
- 小米15真机已验证一次微信付款通知到待确认账目的链路；0.7版把监听与常驻服务放入独立采集进程。**HyperOS清理整个应用时仍可能停止，独立进程不等于永不被杀**。
- 0.7.1加强队列故障恢复、并发导入、状态显示和调试入口保护。采集进程不加载Room，账目由主进程导入。
- 完整备份恢复：照片、消费关联、订阅、缴费链接、支付处理状态及去重身份，以及工资模板、工资单、年度期初和预算；JSON v5兼容旧版v1–4。导入前预览，事务合并，同ID或财务业务键保留本机数据，重复交易与同一期订阅付款避免重复入账。单文件64MB、单张照片8MB。
- 支付待确认支持编辑金额、商户、日期、时间、分类；编辑保存不等于入账。支持多选、全选、按数量确认后的批量入账和忽略。
- 完全重复的采集事件不再重复写队列，商户和交易身份补全仍会处理；识别设置可查看失败数量、重试或确认丢弃失败项。
- 订阅支持全部、启用、停用、7天内到期筛选；本地通知提醒默认关闭，可在订阅页开启。今天/明天到期且未付款的启用订阅参与提醒，通知可打开订阅页，再通过原有缴费链接付款。
- 退款、转账、红包暂不记账；尚未实现无障碍服务。

提醒使用系统非精确调度，计划每天上午9点检查，并在打开应用、修改订阅时检查；实际到达时间受系统后台限制影响。已付/停用不提醒，关闭通知权限时保留未提醒状态，强行停止后需要重新打开应用。提醒不会代替缴费或自动记账。

详见[0.9验收记录](docs/payroll-budget-verification.md)、[0.8验收记录](docs/offline-v8-verification.md)、[0.7后台方案](docs/background-capture-v7.md)、[0.7.1复核](docs/capture-v7.1-verification.md)与[后续改进计划](docs/next-steps.md)。APK、真机截图和原始诊断仅保存在本机，不提交到仓库。

## 0.4.0 订阅记录

- 底部「订阅」入口：概览、彩色卡片、扣费日历、月度预计扣费及分类占比。
- 支持周/月/季度/年付，月末和闰年保持原始周期锚点；支持编辑、停用、恢复、删除。
- 每条订阅可填写完整的 HTTP/HTTPS 缴费网址，点击「去缴费」交给浏览器或对应应用打开。打开链接不会自动记录付款。
- 付款完成后选择「确认付款」，核对计划日期、实际付款日期及金额；可关联已有消费，避免重复记账。
- 预计费用按扣费日期统计，不做年费摊算；已有实际消费不受改价、停用或删除订阅影响。
- 数据库从旧版自动迁移；JSON导出版本2包含订阅与付款关联。0.8起增加可选的本地通知提醒。

## 本机开发

### 0.5.0 饮食与消费

饮食一次记录餐次、可选文字、单张照片与可选金额。填写金额自动生成餐饮消费；支持关联已有消费，金额从关联消费读取，统计不重复计算。照片支持相机和图片选择器，并复制压缩到应用本地目录；JSON版本3包含照片Base64和饮食关联信息。

改价同步更新饮食自动生成的消费；关联既有消费时保留其金额和日期。清空价格只解除关联，删除饮食也保留消费；界面操作前均有说明。

「我的 → 添加示例数据」可添加最近7天的日常和3条订阅；重复点击不重复添加。示例计入统计，记录上有“示例数据”标记。「清除示例数据」仅移除示例及其自动生成的消费，保留个人记录。

若本机模拟器默认渲染启动失败，可使用已验证的软件渲染命令：

```powershell
& "F:\lianbei-build\.tools\android-sdk\emulator\emulator.exe" -avd LianBei_Test -gpu software
```

Kotlin 2.1.20、Compose、Material 3、Room 2.7.1；最低 Android 8.0，编译 SDK 35，Gradle 8.11.1。JDK 17 或兼容的 JDK 21。

用 Android Studio 打开项目并设置 SDK，或者运行：

```powershell
./build-local.ps1 -Test
# 使用本机已有代理时按实际端口传入
./build-local.ps1 -Test -ProxyPort 7897
# 模拟器连接后；脚本只对指定模拟器安装并直接运行测试，不卸载应用
./build-local.ps1 -DeviceTest -ProxyPort 7897
```

安装包构建目标：`app/build/outputs/apk/debug/app-debug.apk`。
